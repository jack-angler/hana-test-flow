1. 테스트 시나리오 DDL 생성요건이야.
2. 테스트 시나리오의 구분단계는 가장 통합테스트 진행명.
   그 아래 단계는 테스트 시나리오ID, 시나리오명이 있어.
   시나리오 ID 아래 단계에는

- 시나리오 진행메뉴
- 시나리오 ID
- 케이스 ID
- 케이스명
- 위치
- 사전조건
- 테스트 스텝
- 예상결과

test_case_results
= 테스트 케이스별 현재 결과

test_case_result_evidences
= 실패/개선/해당없음 결과의 메모, 이미지 증빙

defects
= 결함 관리 대상

defect_assignments / defects.assignee_user_id
= 담당자 지정

defect_actions 또는 defect_comments
= 담당자의 조치 내용, 코멘트, 상태 변경 이력

defect_status_histories
= 접수, 담당자 지정, 조치완료, 확인완료 등의 변경 이력
